On a slide, click Select Photo to choose an image from your computer. The preview is local. Click Download Photo Pack, extract it into your GitHub repository root (so files land in docs/story/images/), then commit and push. Once the photos are live on GitHub Pages, click Publish to Students. This avoids paid Firebase Cloud Storage. JPG, PNG, and WEBP are supported; photos are automatically optimized to WEBP when your browser supports it.

Player progress is tied to stage IDs. IDs are fixed once created; changing stage order or deleting published stages can change which stages unlock. Save Draft is local to this browser and does not save image bytes: download the Photo Pack before refreshing or closing this tab.
